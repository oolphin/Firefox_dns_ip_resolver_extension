🌐 DNS & IP Resolver

Résolution de noms de domaine et d'adresses IP

Résolution manuelle

Exemples: google.com, server1, intranet, 8.8.8.8, 192.168.1.1

Résultats

Historique récent

Paramètres

Obtenez un token gratuit sur ipinfo.io (50,000 requêtes/mois gratuites)

Comment utiliser

  1. Sélectionnez un nom de domaine ou une adresse IP sur n'importe quelle page web
  2. Faites un clic droit pour ouvrir le menu contextuel
  3. Choisissez l'option de résolution appropriée
  4. Les résultats apparaîtront dans une fenêtre superposée
